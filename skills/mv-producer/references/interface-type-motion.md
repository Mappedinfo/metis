# 界面碎彩与巨字动效

用于动态歌词、电子流行或界面叙事 MV 的偏好配置：界面、光标与细密 ASCII
绘图构成可活动的世界，巨字承担视觉焦点，表情和道具回应歌词。背景变化
随叙事展开，漩涡是可选动作之一。具体歌曲和用户明确选择的其他美术方向
优先；该配置不改变画幅、实际唱词、人声时间或生成预算。

## 层次和运动

- 主字保持抓眼的尺度和完整可读性。按实际演唱的短语进入，可用阻尼回弹、
  刹停和错向滑入；不让背景节拍驱动下一句提前出现。
- 背景偏好多色、细碎、丰富的活动：小键帽、纸页、标点、代码碎片、彩色弧线
  和短线。保留速度、景深和密度层次；“丰富”不意味着每件物体各自争抢
  注意力。慢句可以收低活动密度和幅度，为歌词和角色留出安静空间。
- 先按实际唱词和情绪变化规划各段的背景，再选运动方式。可尝试横向流场、
  纵深穿行、ASCII 场景卷动、网格展开与消散、涟漪、纸页折叠堆叠或弹簧波；
  这些是可组合的词汇，不是每首必须凑齐的清单。变化应体现在空间结构、
  运动方向、景深或疏密上，不能让全片始终绕中心旋转，只换颜色和碎片。
- 漩涡适合局部吸入、释放或转场，不作为全片持续底图。选用时须有旋转、
  收拢或释放的轨迹；弹簧要呈现受力、过冲和衰减。不能只放
  螺旋线或写一个特效名称。可让纸页卷入、巨字落下使环境回弹、光标刹停
  带动碎片减速。较慢的歌词仍保留细小呼吸和漂移。
- 把进场、驻留和出场设计成连续动作。保留同一批粒子的相位，让光标、纸边
  或彩线跨镜头传递；旧物沿弧线退出、新物沿相接的运动方向出现。不要每句
  清空舞台后重新摆好一张海报。转场期间，旧歌词按真实尾音撤出，新歌词不
  早于自己的唱词入口。
- 可以用实际音频能量驱动边缘碎片和角色的短促反应；能量包络不是人声词
  时间，更不能用固定 BPM 代替实际演唱。巨字周围留清晰空间，碎彩不盖末字。

## 道具与角色

主视觉中的灯、文件夹等要有经过设计的比例、轮廓、连接结构和受光关系。
例如台灯应能看懂灯罩、开口、支架、关节、底座以及从灯内投出的光；适合时
加入搪瓷、金属、玻璃或纸张的细节。不要用通用灯泡图标、几条粗线或巨大的
“灯”字替代承诺过的完整道具。字可以与物件互动，二者的造型都需成立。

ASCII 角色可保持字符特征，配合姿态、停顿、眼神或呼吸。表情角色采用一致的
轮廓、笔触和材质，让眉眼、嘴形、遮罩和身体动作表现情绪变化；不靠旁边另写
情绪标签。主字、道具、表情共享运动或光影，避免互不相关地漂浮。

## 细密 ASCII 绘图

ASCII 不限于表情字符或飘散代码。可用多行字符绘制完整角色、房间、桌面、
城市或歌词中的物件：先建立能辨认的轮廓、比例与透视，再以字符密度、排线
和留白表现体积、材质与明暗。细节服务具体形象，避免随机字符铺满屏幕。

采用稳定的等宽字符网格，校验字体、字宽、行距和字符覆盖；混用 Unicode
时另查实际宽度。让密度在主体、次要区域与留白之间有层次，细密绘图与巨字
共享画面时给歌词留清晰区域；也可让 ASCII 场景暂作主视觉，再连续接入巨字。

动作可用逐行显影、局部重绘、姿态变化、视差和场景变形，让同一角色或环境
跨镜头演变。保持主体轮廓和字符网格稳定，减少无意义的逐帧随机刷新。细密
不等于把字号缩到看不清，应在最终输出尺寸和实际运动中判断细节是否成立。

## 相称检查

先检查样片中所选动效、慢句和交接点的连续序列，再检查编码后视频。
至少看清一次“旧物退出—新物进入”、一次力场对主动作的反应、一次精细道具
的完整轮廓。全片按段落回看背景，检查空间组织和运动是否有实质变化、同一
旋流是否过度重复；连续性不要求所有镜头沿用同一种背景。细密 ASCII 在最终
尺寸下应能辨认主体，运动中没有明显摩尔纹、字符抖动或闪烁；同时检查整句
可读、下一句未提前、音轨未偏移。静帧、运动数值和机制名称分别只能证明其
检查范围，不能替代实际视听审阅。
