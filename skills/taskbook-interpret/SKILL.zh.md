# 解读文献

按已接受请求选择 `full`（全文）、`question`（局部问题）或 `annotation`（批注）。
保留范围及用户要求的交付语言。局部提问不强制八段报告；只提供一页不证明已读全文。

## 何时使用

用于单篇论文精读、贡献/方法解释、图表提问或段落批注。`full` 读取完整论文；
`question` 回答指定问题；`annotation` 将说明附到可定位的原文。未限定的精读请求
默认全文笔记；有明确问题时默认局部回答。

仅获取论文、多论文综合、正文写作和正式实验执行不适用。后续请求交给相应能力，
不能把本阶段笔记当作后续工作已经完成。

## 方法

1. 确定模式、输入及读者问题，核对论文版本与实际可得页面。区分论文陈述、支撑
   观察与读者解释，保留重要限制及未知。
2. 核对实际可用的 PDF 阅读器与页面渲染工具。文字层缺失或损坏且有 OCR 工具时
   才使用 OCR，对照原页核准数字、公式和标注。`scansci-pdf` 获取论文，下载时
   可选 Markdown 不证明本地 PDF 阅读、OCR 或图表提取；仅需获取时使用。
   记录不可读页。
3. 阅读已接受范围。全文模式覆盖全部章节、图表、附录与参考文献。局部问题读取
   对应原文/图表、图注、定义及回答所需的方法或结果上下文；仅为解除明确依赖
   追加相关章节。上下文缺失时限定回答或将受影响主张标为 `blocked`。记录实际
   页/章节范围，不推定“全文阅读”。
4. 依据证据判断贡献类型：方法、经验发现、理论、数据集/benchmark、综述或系统，
   可以兼有多类。说明局部问题、提出的改变、支持证据及主张限制。这些是分析
   视角，不是强制新颖性排名。理论/综述不强套实验对比模板；未检查相关文献时
   不宣布新颖性。
5. 交付下列对应产物，关键主张均有证据位置。批注保留原文，以精确摘录/位置配
   解释、疑问或建议理解；原生评论仅在工具可用且授权允许时使用，否则交付位置
   索引笔记。笔记文件不证明 PDF 已被批注。
6. 对照已读页检查主张一次，在预算内只修已识别问题。台账覆盖用户要求与 R1–R4：
   `ID | 要求 | done/blocked/n/a | 证据或理由`。`n/a` 须有范围理由，不能免除
   已要求的结果。记录覆盖范围和待补输入。

### 全文笔记

使用 `精读笔记.md` 或用户指定格式与文件名：

1. 一句话概括：论文做了什么、结论是什么。
2. 研究问题与动机，含有依据的贡献类型。
3. 核心主张及章节/页/图表证据位置。
4. 方法、数据、来源与结果所依赖的假设。
5. 局限与疑点，区分作者自述与读者疑问。
6. 证据等级及精确阅读范围。仅摘要/元数据笔记是全文请求的部分结果，不是完成替代。
7. 可借鉴之处及适用条件。
8. 三类参考文献：主要引用及其论证作用；重要的已引领域文献及理由；未被论文引用
   的 AI 补充，每条标“AI 建议，待核实”。原参考文献列表是已引用信息的依据。
   无法确认的作品不列，或改给检索式。

### 局部回答或批注

先回答问题，再根据已读上下文说明必要概念、证据和限制，附位置及未解决依赖。
批注采用 `位置 | 原文精确摘录 | 说明/疑问`，或获授权编辑器的评论对象。只做相关
贡献分析，不追加全文结构或虚构的文献综述。

虚构前向练习见[局部阅读案例](examples/scoped-reading.zh.md)。

## 要求

- [B] R1 阅读范围符合模式与请求 — 验证：全文模式覆盖全部章节、图表、附录、
  参考文献；局部模式记录指定对象与必要上下文。必需材料缺失时保持 `blocked`，
  有用的部分笔记不免除缺失项。
- [B] R2 所需产物与关键主张有依据 — 验证：全文笔记含八节；局部回答/批注回应
  指定问题，不强制全文报告。逐项核对原位置、适用贡献类型、假设及局限。
- [B] R3 来源与解释区分 — 验证：已读材料没有的主张标为不可得，不编造；全文
  笔记三类文献分列，每条 AI 补充有标注。
- [B] R4 台账与检查反映实际工作 — 验证：核对范围、交付物、覆盖、证据和全部
  适用要求；位置索引笔记不能表述为已修改原 PDF。

## 何时停止

使用一次限定阅读/分析、最多一轮定向修复和一次受影响上下文检查。全部适用
必要项有通过证据后交付。输入/工具/上下文缺失或预算耗尽时，交付有用的部分
回答，并列已完成与 `blocked` 项、实际覆盖、停止条件和最小解除条件。不宣称
完整验收，不重开已通过检查；继续范围内可独立完成的部分。

## 产出契约

按指定语言交付所需笔记、局部回答或批注。保护原始资料；不能仅为保存评论就
修改 PDF 或写出用户指定/获授权的位置。台账与覆盖说明留在已有笔记或交付
总结中。分析与正文写作、正式实验执行分别承担。
