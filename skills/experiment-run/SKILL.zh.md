# 实验运行

把已明确问题和执行条件的研究实验运行完，保留原始运行证据，并与接受目标比较。

## 范围

用户要求实际实验或复现时使用。仅要数据缺口、计划和脚手架用 `taskbook-reproduce`；
问题尚未明确时先做问题判断。本地协议不授权新云资源、付费服务、凭据或额外私人研究访问。

## 复现与适配

区分精确复现、方法适配与新消融。原版数据、版本和超参完全一致只约束精确复现声明，
不是已授权适配实验的前提；不得擅自将精确复现目标改为适配。

先在范围内查现有资产、上游运行、论文引用和公开来源；说明查找范围与尚未找到项，
不以一次未找到断言不存在。类别可统一清理、分词、真实翻译及父类回退；评价前固定
规则，在现有协议/报告简记实际计数加权覆盖、OOV与差异，不设100%匹配或统一比例
门槛，不用评价分数选择映射。

保留真实数据、语义、向量来源、列计数对应、训练测试隔离与时间敏感特征对时。
高频歧义、关键语义损失、跨时间替代等会改变研究问题的近似，列具体例子、涉及计数
和影响交用户判断；沿用已有决定，不逐词审批，不擅自采用未授权的重大替代。
独立可做的已授权部分继续；适配如实命名，复用已有记录和有效检查，不另建追溯体系。

## 阶段任务、交接与报告

路由时只列本次要求的阶段和产物，每阶段先读取选定技能的入口；产物审查使用
`run-review` 时也先读取其入口。宿主有任务清单时显示待做、阻塞与完成；没有则复用
项目任务记录。交接携带协议、输入及版本、偏离、运行状态、产物、证据缺口和验收条件；
接收方核对输入，缺失的必要项保持未完成。提及技能不等于证明已读取。

要求完整实验报告时，读取并执行适用的项目或宿主报告规范，覆盖问题与目标、数据、
方法、结果、分析、讨论及复现；引用证据，缺项明确说明及其影响。分别判断报告完整性、
预先性能标准和主张支持。启动或运行完成不等于报告完成；简短进度稿链接底层记录，
不擅自扩成完整报告。公共技能不依赖某个私人技能或调度器。

## 方法

1. 写明科学问题、目标、对照、最小有区分力的运行、限制与停止条件。精确复现、方法适配
   和新消融分开记录，修正实现也须说明，避免把改过的实现称为官方原样基线。
2. 映射实际涉及的代码、数据、样本单位、分区、预处理、指标、依赖和资源。检查泄漏、
   跨分区身份、测试集调参和对照容量；原始资料保留，变化单独记录。
3. 冻结命令、输入、随机种子、必需输出、时间／资源上限和已提供的数值验收条件。
   未提供论文数字或容差时不编造；实际接受模式下的关键数据或权限缺失只阻塞受影响
   的执行/声明，独立可做的已授权部分继续；仅缺原版不阻塞可行且已接受的适配。
4. 必要时先做低成本入口检查并标为 smoke，再运行已授权评价。保留实际命令、代码／数据
   哈希、环境版本或锁文件、种子、原始输出及日志。写了种子不证明所有库都已设置，也不证明稳定。
5. 分别核验产物与数值含义。将目标、观察、分母、不确定性、协议偏差和失败案例对照。
   `run-review` 可检查原件完整性，科学判断仍须直接核对协议、指标和来源。
6. 按原问题关闭要求台账；新发现不能自动替换目标或启动更多实验。

有界本地运行使用[本地协议](references/local-protocol.md)。标准库辅助程序不用 shell，
保存失败、超时和缺失产物。远程／GPU 后端仅在当前可用且获准时接入，核心不依赖私人 LAN。

## 验收要求

- [B] R1 运行前有明确协议、预算和目标，保存内容与命令一致。
- [B] R2 检查实际输入、哈希、版本／锁文件、种子和日志。
- [B] R3 分开验证程序成功、必需产物和数值结果；缺产物或未经核对的结论不能算完成。
- [B] R4 原协议、修正和扩展可追溯，无隐性调参或换题。
- [B] R5 台账区分准备、smoke、执行、科学验证，每项附实际证据。

## 停止与交付

默认一次正式运行、必要时一次入口 smoke、最多一次针对性修复／重跑和一次最终审查，
均受明确时间与资源上限约束。失败记录保留；达成验收或预算耗尽时停止，报告完成项、
未完成项及最小解除条件。交付协议、manifest、原始日志／指标、再生成入口、目标对照、
偏差和台账。成功启动或 smoke 不证明科研结果。
