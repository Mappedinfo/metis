# scientific-plot：计算结果与自定义科研图

[唯一发现入口](SKILL.md)。本文件为中文主稿，入口为配套英文译文；两份同步维护
执行要求，发现入口的文件名不赋予任何一种语言语义优先权。

## 何时使用

适用于数值数组、已有模型输出、学习曲线、诊断图、自定义面板，以及用户明确要求的
算法演示图。选图建议和图形审查可以使用所给图件，无须生成数据。

输入为准备好的 CSV、图型在 `table-chart` 的渲染范围内时，直接使用该技能。
项目名称或绘图库不能单独决定技能选择。本技能负责数值图形制作；研究实验、统计推断、
文献发现、地图处理和可编辑机制图分别使用对应能力。已有分析可用时直接复用，
不要为重画图重新运行分析。

## 方法

1. 从请求确定读者问题、输入、用途、输出，以及选图建议、审查、制作或修改模式。
   区分观测数据、已有计算结果与生成的教学数据。真实结果缺失时说明缺失输入；
   只有演示请求才允许生成演示数据。保留用户要求的范围和图件数量。
2. 按问题选择编码与面板安排，保留单位、分母、样本对应关系及有效比较。
   投影图不能证明因果或聚类可靠；固定种子保证一次运行可复现，不能证明稳定性。
   图注说明计算内容和比较边界，包括标签是否参与模型拟合。
3. 读取项目选择的 `profiles/<name>.yaml`。`journal`、`journal-grayscale`、
   `journal-npg` 是可选风格，不要求每次交付三套图。配色、字体、尺寸和导出默认值
   从所选 profile 读取。用户或投稿规范有明确覆盖要求时遵守并记录。
   缺失的 profile 按[安装指南](https://github.com/mappedinfo/metis/blob/main/profiles/README.md)
   在授权范围内补齐，保留已有变体；不要因为缺失就改用个人样式或复制私人素材。
4. 复用项目绘图入口与已经选定的后端。已有 Python 或 R 流程足以确定后端；
   否则选用合适的可用后端，只有会实质影响交付时才询问。计算与渲染分离，缓存
   计算值，记录输入、参数、随机种子和依赖版本。教学演示所需的轻量计算保存在
   可复现源码中；新增研究实验仍是独立阶段。
   制作或修改时读取[制作与验证](references/production.zh.md)，尤其是多面板和委派场景。
5. 遵守 profile 的下方标注约定：整图标题、图注放在整图下方，每个面板的标题或
   图注放在该面板下方，轴标签留在轴旁。不要用 `suptitle` 或 `set_title` 承担图注。
   用户或投稿规范明确要求其他位置时可以覆盖。先预留空间，再固定轴的布局并测量
   文本边界；只移动整图图注不能修复仍在顶部的面板图注。
6. 按目标尺寸导出要求的格式，查看实际文件，记录文字可读性、重叠、裁切、单位、
   尺度、面板对应关系和组别辨识。颜色承担信息时检查灰度视图。要求可编辑矢量文字时，
   重新打开 SVG/PDF 检查文字对象，不能只凭扩展名判断。修复后仅重画受影响产物，
   并更新同一份验收台账。

对用户要求与下方 R1–R7 逐项记录 `done`、`blocked` 或 `n/a`，附证据或范围理由。
只请求规划时验证方案，并标明绘图尚未执行；审查所给图件不要求重写其绘图流程。

## 验收要求

`[B]` 为完成前必须通过的要求，`[A]` 为建议项。R1–R7 用于稳定地对应检查证据，
不是图件或回复的固定章节模板。

- [B] R1 输入与主张边界：核对各面板的来源和变换；标明演示数据，不补造缺失实证结果。
- [B] R2 编码回答问题：对照输入核对单位、分母、尺度可比性、标签是否参与拟合，以及请求中的比较。
- [B] R3 使用项目风格：记录实际 profile 和覆盖要求；检查导出图的风格，以及整图和每个面板的图注位置。
- [B] R4 计算可复现：保存输入或获准的公开加载入口、计算参数、环境和可运行渲染入口；重画使用缓存结果，不重复昂贵分析。
- [B] R5 检查最终文件：按使用尺寸查看实际导出，记录裁切、字形、可读性、组别辨识及必要的可编辑文字检查。
- [B] R6 委派保留要求：采用委派时，工作单元收到技能入口、profile、输入、允许的计算、输出契约及相关检查；协调者检查整合结果。未委派时记为 n/a。
- [A] R7 有用的备选：确有取舍时考虑另一种编码或布局；方案已定时可以省略。

## 何时停止

- 建议或审查请求以所需建议／发现及验收台账结束；制作请求以所需导出、可复现输入
  和全部适用必需项的通过证据结束。
- 每个接受版本进行一次完整视觉检查，最多一轮限定修复，再复查受影响产物。
  预算耗尽时报告已完成项、未完成要求及最小解除条件，未解必需项保持 `blocked`。
  用户提出新修订形成新的接受版本，仍须保留兼容的原要求。

## 交付契约

交付所请求的建议、审查或图件，以及适用的源数据、计算／渲染入口、profile 与覆盖记录、
环境和验收台账。说明实际视觉检查与未解项。文件生成、图注位置断言和技能安装各自只
证明对应检查，不能据此宣称科学结论成立或新宿主会话已自动选择技能。
