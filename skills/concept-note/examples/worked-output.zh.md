# 教学笔记：损失下降为什么不保证召回率上升

召回率衡量真实正例中有多少被判断为正例；概率损失衡量分配给实际答案的概率。
本例为虚构教学数据，不报告模型实证性能。

四条记录的标签为[1,1,0,0]。模型A的概率为[0.60,0.40,0.30,0.20]，模型B为
[0.61,0.49,0.25,0.15]。阈值0.50使两者均预测[1,0,0,0]，因此TP=1、FN=1，
召回率均为1/(1+1)=0.50。

平均负对数概率为 L=-sum(y*ln(p)+(1-y)*ln(1-p))/4，其中y为真实0/1标签，p为
预测正类概率，ln为自然对数，4为记录数。A的L约0.502，B约0.414，损失降低，
但第二个真实正例仍未越过阈值，召回率没有改变。

损失利用连续概率，召回率利用阈值后的判断。在阈值固定、真实正例仍未改变预测
类别时，概率变好可以降低本例损失，却不改变TP和FN。若把阈值降到0.45，模型B
第二个正例越过阈值，召回率将变为1；因此阈值必须一起说明。损失和召回率回答
不同问题，不能把一个当作另一个的保证。

使用时先明确正类含义、阈值与分母，再同时检查概率表现和决策指标。概率是否
校准、真实数据中的稳定性都未由四条教学记录检验。
