# 无人值守复盘与交付

为未来运行准备自包含复盘提示，或检查已有自动复盘时使用。同一 SOP 可在兼容环境中运行，不预设存在调度器、命令行工具或在线主机。提示词草稿是产出物，不是已安装或执行的任务。

## 准备自包含提示

包含已确定的范围、区间/时区、基准、允许的证据、输出目标、写入/动作边界、轮数预算与验收检查。目标环境可能没有本 skill 时，直接写出必要步骤。未确定占位符保持可见；如果影响访问或正确性，不能称提示词可直接运行。

```text
复盘范围：<指定任务/项目和允许的证据根目录>
复盘区间与时区：<已确定区间、时区或已知局限>
基准：<已接受目标/检查点，或明确缺失>
研究主线，仅研究任务需要：<已接受问题/范围或明确不确定性>
输出目标与语言：<对话或已授权现有目标；语言>
权限：<只读，以及任何明确获准的目标/动作>
证据预算：<有界轮数与来源短名单>

1. 检查允许的证据并与基准比较。分清观察、解释、已接受或拟议决策、行动。
   区分真实结果与计划、已启动或未验证的工作。
2. 解释重要变化或阻塞，总结证据、影响与不确定性。只有任务要求或已接受契约
   确立时，才使用研究主线或学习视角。
3. 最多执行明确获准的一项有界推进，并验证效果；否则描述确切下一步，不执行。
4. 产出状态真实、验收明确、依赖清楚且在制品上限现实的下一步计划，保留必需结果范围。
5. 如有获准目标，仅写入该目标。对齐该复盘区间已有检查点，不创建重复状态。
6. 汇报已检查来源、实际改动、验证、验收台账、停止条件、缺口与最小解除条件。
```

准备提示词不授权创建、更新、启动、禁用或删除定时任务。只有该动作已被请求并获授权时，才通过目标环境支持的调度接口操作。个人设置中的节奏不能代替授权。不能把新增第二个调度器或自行触发的复盘循环作为复盘副作用。

## 逐层验证交付链

| 层次 | 承诺该层时所需证据 |
|---|---|
| 配置 | 预期任务或规则确实保存在目标调度器中 |
| 触发 | 对应区间真实触发的记录，而不只是未来规则 |
| 运行环境 | 正确任务和环境实际启动 |
| 工作 | 请求的复盘和获准动作实际完成 |
| 产出物 | 目标输出存在，且实质内容已检查 |
| 持久化 | 已回读最终运行状态及获准状态更新 |
| 送达 | 承诺的会话、链接、通知或界面目标中含有结果 |

未检查层标为未验证，明确汇报已知故障所在层。正常退出不能证明产出物；缺少交付链接也不能证明底层工作没执行。在许可根目录中检查相关清单、日志、产出物和目标状态，不猜测特定环境原因。

## 约束无人值守恢复

保留并发重叠保护、约定检查/重试上限和真实失败状态。按复盘身份与区间对齐重复运行；不能因为包装程序运行两次就新增检查点或推进学习计数。重试副作用不确定的操作前，先检查是否已改变目标。

凭据、来源访问、主机、适配器或写目标不可用时，说明受影响层与部分结果。不能据此推断有权绕过访问控制、迁移存储、虚构交付成功或改变调度。未来运行环境尚未配置时，仍可交付已准备好的提示词，但要明确两者区别。
