# 本地候选扫描器

仅在使用可选辅助程序时阅读本参考。先完成[技能主流程](../SKILL.zh.md)要求的语义通读。
辅助程序使用 Python 3.10+ 标准库，无网络请求、额外软件包依赖、自动改写、外部检测器或作者来源评分。
它读取输入和配置，将报告写到标准输出。

## 运行

本地 Python 运行时可用时，从仓库根目录执行：

```bash
uv run --offline --no-project python skills/prose-audit/scripts/detect.py draft.md --json
uv run --offline --no-project python skills/prose-audit/scripts/detect.py draft.md --json --config thresholds.json
uv run --offline --no-project python skills/prose-audit/scripts/detect.py draft.md --json --include-quotes
```

已安装技能的 `scripts/detect.py` 路径相对于该技能目录解析。
`INPUT` 必须是普通 UTF-8 纯文本或 Markdown 文件，最多 2,000,000 字节。
不支持标准输入模式或 PDF/Word 提取。超大文件会被拒绝，不会被截断。
若需提取或分块，在辅助程序外完成，并记录实际覆盖范围及来源位置映射。

不加 `--json` 时，程序输出便于阅读的候选报告，限制相同。
退出码 `0` 只表示输入已处理，包含空输入或零候选情况，不代表文字通过审校。
退出码 `2` 表示输入、配置、参数无效或读取失败。只修复具体的本地问题，不转而把文字上传到其他服务。

## 规则与阈值

[scripts/rules.json](../scripts/rules.json) 是有限词表、明确词形、小型繁体字映射表、表层模式和默认阈值的
唯一可执行来源。[信号判断指南](signal-guide.zh.md) 提供定性判断，不复制一份机器可读字典。

这些默认值是一种候选复查约定，不是经过实证校准的质量或作者来源判据：

| 配置键 | 默认值 | 含义 |
|---|---|---|
| `tier1_document` | 1 | 某个 Tier 1 规则词族在扫描文档中至少出现一次。 |
| `tier2_document` | 4 | 某个 Tier 2 规则词族在扫描文档中至少出现四次。 |
| `tier2_paragraph` | 3 | 某个 Tier 2 规则词族在同一扫描段落中至少出现三次；满足此条件也会入选。 |
| `tier3_document` | 3 | 某个 Tier 3 规则词族在扫描文档中至少出现三次。 |

计数**逐个规则词族**进行，合并该规则列明的别名及明确词形，也包括被归入同一规则的跨语言形式。
不是把整个档位的所有词汇加总。重叠词汇先保留最长词组，再计数；长度相同则按存储的规则顺序选择。
因此，“holistic”和“holistic approach”两项不会重复计算同一次出现。
这种约定可能省略较短候选，不代表对任一表达作出语义判断。

可选 JSON 对象只覆盖其中提供的配置键：

```json
{
  "tier2_document": 5,
  "tier2_paragraph": 4
}
```

配置最多 16,384 字节。值必须为正整数；未知键、重复键、布尔值、字符串、小数、零和负数均被拒绝。
解释结果时记录覆盖值。提高阈值会减少展示的候选，不会减少语义审校的必要性。

## 匹配覆盖什么

- Unicode NFKC 规范化、大小写折叠、弯引号撇号折叠及小型字符别名表作用于匹配视图，原文不变。
  这不是完整繁简转换、中文分词或英语词形还原。
- 英文词汇使用明确词形及拉丁文字边界，不应在更长英文单词内部命中。
  混合语言文本使用同一规则集合。多词表达可跨换行空白匹配；罕见词形和复杂句式可能漏检。
- 当前表层模式覆盖部分中英文分句否定、对比和重要性主张。
  同一段中，在相邻近似句子里重复出现的已列明强化词，会产生 `adjacent_repetition:<id>` 候选，
  不受词汇频次阈值限制；不会跨受保护片段连接。
- 格式辅助仅覆盖 `bold_label_list`，并未覆盖指南中的每一种标题样式、emoji、三项并列、连接词链、
  被动语态或视觉模式。同义循环、假范围、强调是否合理、术语是否相关，以及证据质量，始终需要阅读判断。
  命中不证明存在缺陷。

## 受保护内容与覆盖范围

默认按启发式规则排除 YAML 前置信息、围栏和缩进代码、行内代码、数学式、HTML 注释及标签、
URL/链接目标、引用式链接定义行、块引用和成对引号片段。可读的 Markdown 链接标签仍参与匹配。
未闭合的前置信息、代码围栏或注释可能使文档余下部分都受到保护。
这是一种保守启发式处理，不是完整 Markdown 或引号解析器；格式损坏、嵌套、转义或特殊结构可能被误判。

`--include-quotes` 使已识别的块引用及直引号、弯引号、中日韩式成对引号片段重新参与扫描。
它不恢复代码、数学式或其他字面区域，也不授权修改来源引文。
若 Markdown 块引用符号只用于包裹用户提供的整篇草稿，可将正文另存为输入，或有意使用该选项。
语义审校仍须识别草稿内真正的引文。

受保护字符不计入匹配次数或描述性长度。全文受保护、空输入或没有可识别语言单位时，可能返回
`input_status: insufficient_text`，不能据此称为审校无问题。
`input_status: scanned` 也可能只对应很短的片段。必须自行阅读原输入和排除区域，说明实际审校范围。
辅助程序不能把部分访问变为全文覆盖。

## 阅读报告

JSON 包含：

| 字段 | 解释 |
|---|---|
| `schema_version` | 当前为 `1`。 |
| `review_status` | 始终为 `candidate_scan_only`。 |
| `context_review_required` | 始终为 `true`，零候选时也一样。 |
| `input_status` | `scanned` 或 `insufficient_text`；是处理状态，不是评级。 |
| `thresholds` | 校验并应用覆盖后的实际阈值。 |
| `candidates` | 包含 `kind`、`rule_id`、`message` 和 `locations`；词汇候选还包含 `tier` 和 `counts`。 |
| `statistics` | 描述性句长、段长、数量、均值、总体标准差及受保护字符数。 |
| `limitations` | 每次扫描均返回的解释及覆盖限制。 |

候选类型为 `vocabulary`、`syntax` 和 `formatting`。
词汇计数包含 `document` 和 `paragraph_max`。每个位置包含 `start`、`end`、`text`、
`line`、`column`、`end_line` 和 `end_column`。
偏移量是原输入中从零开始的 Unicode **码点**位置，末端不包含在片段内：
`original[start:end] == text`。它不是 UTF-8 字节偏移或 UTF-16 编辑器偏移。
行、列从一开始；BOM 算一个原文字符，CRLF 算一次换行。审校发现应引用返回的原文 `text`，
而不是规范化后的匹配文字。

长度单位近似为汉字加规范化后的 ASCII 英语词，词内可包含撇号。
数字和受保护片段不计入单位。空行近似划分段落，标点及换行近似划分句子，
因此缩写、折行、其他语言和复杂标记可能影响统计。长度列表为空时，均值和标准差为 `null`。
没有句长阈值、突发性判定、综合疑似评分或文字质量等级。

扫描后，在语境中确认或排除候选、合并重复，只将有依据的发现纳入编辑报告。
准确区分“扫描器运行完成”与“语义审校完成”。
