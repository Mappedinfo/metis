# 结合语境判断信号

用本指南判断候选表达是否妨碍写作目的。行动前阅读该句、相邻句子及其在全文中的作用。
以下示例用于说明判断方法；可执行词表和阈值只维护在 [rules.json](../scripts/rules.json) 中。
档位编号是候选筛选设置，不是严重程度分类。

## 词汇、抽象与强调

**过程黑话。** 契约、边界、回执、对齐、闭环、生态及类似表达，需要有可识别的指代对象。
普通进展记录中的“完成指标回执”，可能没有说清究竟是测量、检查还是记录。
先从上下文确定实际动作，再选择替换词。真实的 API 契约、验收条件、法律合同或科学结论的适用限制，
可能正需要这些词。

**领域术语。** 幻觉、token、提示注入、agent、温度参数、framework、paradigm 等可能具有技术含义。
准确指称主题时予以保留。读者需要解释时，定义术语，而不是为了减少命中而删掉概念。
在非技术用法中，先指出它掩盖了什么动作或主张，再判断是否属于黑话。

**执行提醒混入正文。** “不冒充全局”“真实口径”等可能是写作者的内部指令进入了读者正文。
先判断任务是否讨论写作过程本身。否则，用已有的覆盖范围、证据来源、时间、方法或动作表达，
或删除空泛保证。“样本仅来自三个城市”和真实不确定性会影响解读，需要保留。
材料缺少细节时指出缺口，不补造范围或测量值。

**声势与程度。** “pivotal”“robust”“holistic”“赋能”“极其关键”等词需要结合语境判断，不能自动删除。
检查强调描述了什么结果、比较、条件或读者决策。
有依据的“对这些指定扰动保持稳健”应保留；无解释的赞美则需要限定或删除。
形容词出现频繁，本身不构成缺陷。

**推广与情绪。** 对照体裁检查“boasts”“stunning”“震撼”“眼前一亮”等表达。
“Located in”或“坐落于”可能只是在陈述位置。
用户提供的个人感受在回忆文字中可能合适；中性报告则可能需要事实描述。
不得为使改稿显得个人化而虚构经历或感官细节。

## 句间关系

**否定与对比。** 先确定文体，再判断分句否定（“This is not X. This is Y.”）、“不是 X，而是 Y”、
“不在……而在……”及连续“这不是……那不是……”。科研正文和学术综述（`academic`）将修辞铺垫
标为修改项，直接陈述对象、方法或结果，例如“本研究记录降雨概率。”
科普、教学、口播（`explain`）按语境判断；“记录的不是降雨量，而是降雨概率”可用于纠正常见误解。
通用正文也须按语境判断。真实的方法比较或必要限制保留其信息，适当时直接陈述，
例如“本研究预测降雨概率，基线模型预测降雨量。”
被否定的选项没有来由、所谓对立不成立或反复拖延时修改；仅换标点不能修复这种推理问题。

**三项并列。** 三个成员各不相同且都相关时，三项结构有用，例如三种明确的实验条件。
检查强凑对称、内容重叠和无解释的多余项。不要为打破模式而删掉有效项或编出第四项。

**衔接与惯用开场。** “first”“therefore”“in other words”“首先”“当然”“更麻烦的是”
“说到这里”等连接词链，只有表达实际顺序或关系时才有用。保留有效的路标。
衔接重复则删除；关系缺乏文本支持则修正。因果连接词可能暴露实质证据缺口。

**程度词重复。** 相邻句子反复使用同一强化词，即使未达到频次阈值，也值得检查。
核对被强化的主张以及第二句是否增加信息。
“很 + 形容词”“高度 + 抽象名词”“有很 X 的感觉”等形式是阅读提示，
不是完整语法定义，也不天然是缺陷。

**被动开头与行动者缺失。** 被动语态可以合理突出对象或过程。
“is widely believed”或“被广泛认为”隐藏了必要来源或归属时才修改。
只补入已知的行动者。对“越……越……”，检查主体能否从上下文恢复，以及所述关系是否有依据；
中文常见的省略主语本身不是错误。

**重要性吹胀与表面分析。** “Marking a pivotal moment”“highlighting its importance”
“体现了”“反映了”可能附加结论，却没有解释从观察到结论的联系。
检查它增加了什么推断、依据是什么，以及改变了读者的什么判断。
保留有依据的解释；删除空洞尾句或指出缺失理由。英语分词以“-ing”结尾，本身不是缺陷。

## 跨段含义

**同义循环。** 不同词也可能重复同一主张，即使没有字面重复。
比较命题：“窄”“小”“浅”在此是否增加了不同维度，还是重复无依据的判断？
只合并真实冗余，保留人群、尺度、机制或后果方面的差别。
重复同一关键词也可能是在保持指代清楚。固定词数不能证明同义循环。

**假范围。** 对“from X to Y”或“从 X 到 Y，从 A 到 B”，明确连接端点的轴或过程。
日期、测量范围、阶段，以及解释清楚的转换都可能合理。
只有文字暗示了尚未建立的连续性或递进关系时，才判断为假范围。
说明缺失关系；表层匹配不能代为判断。

**模板结尾。** 总结有时能帮助读者使用长篇论证。检查总结是否给出判断、说明推论，或归纳必要的要点。
只有结尾在重复且不服务于已接受目的时才删除。
结论标题或“综上所述”不足以证明问题。

## 形式与呈现

句长和段长可以描述节奏，但不能证明作者来源，也没有通用理想值。
不得套用“AI 常写 12–18 词”之类范围或标准差阈值。
结合语言和体裁判断文字是否单调、信息过载或难以跟随，只修改造成实际阅读影响的部分。

Title Case、术语加粗、emoji 和 `**Label**: explanation` 列表，可能服务于导航或符合既定样式。
检查重点过多、层级不一致及读者不适配。技术说明可能受益于重复标签。
不要因为像模板就全局删除格式。扫描器只覆盖其文档列明的表层形式，实际结构仍须人工语义审校。

## 校准与历史背景

本技能的辅助程序使用本地规则，没有经过训练或校准的作者来源模型，计数仅用于定位表达。
不得汇总成“AI 概率”、编造置信百分比，或把口语、拼写错误、情绪变化及具体细节当作真实性证据。

两个历史案例说明作者来源判断需要自身的证据：OpenAI 于 2023 年 7 月因准确率低而下线其特定分类器
（[OpenAI 公告](https://openai.com/index/new-ai-classifier-for-indicating-ai-written-text/)）；
Liang 等人在 2023 年测试的检测器和样本中，报告了非英语母语者文本被误分类的问题
（[Patterns 论文](https://doi.org/10.1016/j.patter.2023.100779)）。
这些发现限于对应系统与情境，既不验证本辅助程序，也不能据此断言当今所有检测器的表现。
