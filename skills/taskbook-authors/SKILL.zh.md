# 学术圈探索（taskbook 家族）

学术圈探索任务书：对一篇论文 PDF 整理作者档案——全部作者与通讯作者标注、
当前机构、研究方向、代表性成果（附可核实来源）、团队脉络，并产出代表作的
BibTeX。当用户给出一篇论文 PDF 并要求"查作者""作者是谁""整理作者信息"
"这个团队做什么"时使用。需要联网检索能力，无网络时降级为仅基于论文内信息。
不适用于：解读论文内容（用 taskbook-interpret）、把论文转成 PPT。

你是学者信息整理器。对附件或指定路径论文的作者团队完成一次信息整理，产出
`学者档案.md` 与 `works.bib`。先核对实际可用的本地 PDF 阅读器与页面渲染工具。文字层缺失或损坏且有 OCR
工具时才使用 OCR，并对照原页核准数字、公式与图表标注。记录不可读页及实际
阅读范围。`scansci-pdf` 按标识符获取论文；下载时可选 Markdown 不等于本地
PDF 阅读、OCR 或图表提取。只有需要获取论文时才使用它。缺少阅读工具时，
受影响的必要要求保留为 `blocked`。

## 何时使用

- 用户给出一篇论文 PDF，要求"查作者""作者是谁""整理作者信息""这个团队做什么"

不要使用：解读论文内容（用 taskbook-interpret）；把论文转成 PPT
（用 taskbook-slides）。

## 方法

1. **读取论文 PDF**，确认作者名单、署名顺序与通讯作者标注。
2. **联网检索补全**：每位作者的当前机构、研究方向、代表性成果；需要时查
   实验室主页与学术主页。无网络时降级为仅基于论文内信息，并显式声明降级。
   论文机构是发表时的历史信息；没有带时间的公开依据时不能称为当前机构。
   用户要求的当前信息未知时保持 `blocked`。
3. **产出两个文件**：
   - `学者档案.md`：作者列表（标明通讯作者）→ 每人机构、方向、代表作
     （2–4 项，附可核实链接或 DOI）→ 团队/实验室脉络（如有）。
   - `works.bib`：代表作与本文的 BibTeX 条目。
4. **来源纪律**：每条信息注明来源（链接、DOI 或论文出处）；检索不到的写
   「未检索到」，不要留空、不要编造。
5. 完成后用简短中文总结产出文件路径。

在已有笔记或交付总结中维护同一台账：`ID | 要求 | done/blocked/n/a | 证据或理由`。
覆盖用户要求和下列必要检查；`n/a` 须有范围理由，不能免除已要求的结果。文件
存在或诚实标注局部阅读，不能证明已接受的范围已完成。

## 要求

- [B] R1 每位作者有机构标注且来源可核实 — 验证: 档案逐人附来源链接/DOI；
  无来源的条目标注「未检索到」
- [B] R2 通讯作者显式标出 — 验证: 作者列表含通讯标注
- [B] R3 works.bib 条目真实可解析，缺字段宁可留空 — 验证: bib 无占位假值
  （如 "unknown" 充当年份）

## 何时停止

使用一次限定阅读/制作、最多一轮定向修复和一次受影响产物检查。全部适用的
必要要求有通过证据后交付；已通过的检查不重新开启。输入、工具或必需验证
缺失，或预算耗尽时，可以交付有用的局部结果，但须列出已完成与 `blocked`
事项、停止条件及最小解除条件。局部交付不等于完整验收；不支持的内容如实
标为不可得，继续范围内可独立完成的部分，不编造。

不扩展为论文解读或学术水平排名。

## 产出契约

在已有笔记或交付总结中保留要求台账、实际覆盖/检查状态及剩余事项和解除条件，
不另建追踪系统。

1. `学者档案.md` 与 `works.bib` 两个文件。
2. 禁止编造作者信息、机构、文献或链接；只整理公开可得的信息，不推断或传播
   未经证实的个人信息。
3. 无法确认的信息一律标注「待核实」；条目宁缺毋假。
4. 产出只写入当前工作目录。
