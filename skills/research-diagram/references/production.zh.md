# 可执行制作与文件检查

制作时读取。先复用项目可用后端；以下命令是假定已有 Mermaid CLI 的本地调用，
不是自动安装或远程服务调用。没有渲染器时，在获准的环境准备范围内安装明确版本，
或交源码并把渲染项标为 blocked。不要把“已写源码”记为“已查看 SVG”。

## Mermaid 到 SVG

1. 保存 UTF-8 `.mmd`，使用稳定节点 ID 与短标签。科学符号需要可用字体；箭头标签
   说明数据／反馈含义。正文中的引号、括号和 HTML 特殊字符按 Mermaid 语法处理。
2. 将项目 profile 的字体、颜色、背景映射到 Mermaid 的 `themeVariables`，放入单独
   JSON 配置。保留 profile 名称与覆盖要求；profile 规定的外部图注不要挤进流程节点。
3. 本地 CLI 示例：

```sh
mmdc -i method.mmd -o method.svg -c mermaid-config.json -b transparent
```

若使用现有 Chrome，可向 CLI 传 `-p puppeteer-config.json`，配置为
`{"executablePath":"<已核验的本地Chrome路径>"}`。路径属于任务运行记录，不写进
共享技能。命令返回成功只证明导出执行；记录实际 renderer 和版本。
若 profile 要求下方图注，可在 `.mmd` 写一行或多行 `%% caption: 图注文字`，然后
运行本技能的标准库帮助程序（路径以当前技能位置为准）：

```sh
python scripts/add_caption.py method.mmd raw.svg method.svg --font-size 16 --width-mm 183
```

帮助程序保留原始渲染文件，只扩展画布并添加文字；`--width-mm` 按 profile 或接受
要求设置最终物理宽度，并保留纵横比。字号、字体和文字色需按 profile
或已接受的预览覆盖传入，长图注由源码中的多行注释分行。程序不自动测量文字宽度，
必须查看最终文件并按实际裁切／重叠修复。

4. 解析导出的 SVG，检查可打开、viewBox 非空、请求标签存在和字体可用。把 SVG
   用可用图像查看器／浏览器渲染，按最终尺寸看字形、重叠、箭头连接、阅读路径。
   转 PNG 预览时保留原始 SVG；预览文件不是可编辑源码。
5. 对照节点／边映射检查每条关系：条件分支是否标了条件，反馈是否回到正确阶段，
   因果、相关、流转和依赖是否区别。只检查标签数量不能证明关系正确。

## draw.io

按请求交 `.drawio`。使用 `mxCell` 顶点存文字与框，edge 存 source、target 和箭头；
原生关系不要烘焙进图片。可选插图只承担形态内容，来源需可用并有许可依据。

保存后用可用 draw.io 应用或兼容后端打开并导出所求文件。原生编辑验收时复制一份，
改一个标签和连接器端点，保存重开；核对文字、端点和组关系保留。XML 解析可以证明
对象与引用存在，不能代替实际应用编辑和视觉检查。要求应用编辑但环境不可用时
明确保持该项 blocked；别用单张 SVG／PNG 冒充 draw.io。

## 委派和记录

工作单元收到技能入口、所选 profile、原始材料、允许的推断／演示、图件数量、源码
格式、导出格式与验收要求。协调者检查实际整合图与边含义，不能只接收“已完成”的消息。
渲染配置、版本、源码及视觉观察留在任务工作记录；读者图注只放理解图形需要的信息。

若改用其他 SVG 制作后端，必须从同一份节点／边源码驱动导出；另写硬编码节点和关系的脚本不能证明 Mermaid 源码与图件一致。缺少真正渲染或目视检查时保留 blocked，不能用结构计数代替。
