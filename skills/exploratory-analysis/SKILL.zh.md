# 探索分析

检查可获得的数据能支持什么，先了解原始结构、覆盖与异常，再选择正式分析。

## 范围

用于分布、缺失、异常、分组和描述关联。先检查原始结构与覆盖；含义或转换规则不清时，依赖转换的步骤使用 `data-preparation`；
只要求出图时直接选择绘图能力。测量验证、正式推断和因果设计各自需要明确假设与方法。

## 科研数据首次检查

科研任务取得或使用尚无适用分析的数据时，正式分析或评价前逐个检查获准的数据集；
已有结果须核对来源/版本、单位、字段、筛选与范围后复用。尊重测试集封存，不为探索
违反协议查看或使用标签。在项目既有位置保存 Markdown 数据分析报告、实际图件及可重跑
计算。覆盖数值/类别分布与频次、缺失/无效/压制/结构性缺失与观测零值、带分母的覆盖率；
适用时检查时间范围、频率、分辨率和缺口，以及空间范围、粒度、CRS 和覆盖地图。按数据
画直方图、时间图和地图；不适用、未知或阻塞写原因。检查实际图件并保留原始数据。
总体统计可分块/流式，抽样图注明覆盖；不对未变化的有效分析重复运行。仅下载文件或
只阅读论文而未使用数据时不自动扩大任务。

## 方法

1. 明确观测单位与抽样单位、来源、时间窗口、单位、键、权重和检查目的。识别面板、聚类、
   重复观测及选择规则；行数不自动等于独立样本量。
2. 按变量和相关组检查缺失、常量、范围、单位冲突与重复身份。缺失机制是待检验解释；
   结合测量语境判断异常，保留原件，异常标记不产生删行授权。
3. 报告数量、适用的分位数、中心和离散程度，以及各组分母和空组。分类、有序、删失和
   零膨胀变量选择适当描述，不统一套正态摘要。
4. 先检查时间与组别构成，再看汇总关联；每一对关联保留完整配对数。检查尺度、非线性、
   汇总与组内方向相反的情形和依赖关系；相关系数不证明因果方向。
5. 把观察、替代解释、质量决定与后续检验分开。看数据后形成的假设保留探索身份，
   正式验证使用新的验证证据或明确探索范围。
6. 对照实际记录核数，维护台账。需要图形时使用项目 profile 和相应绘图能力，查看实际
   导出文件，保留输入和转换依据。

可选标准库程序 `scripts/describe.py` 要求 Python 3.10+、显式数值列、标识符和观测单位；
用法见英文入口。它只把空格单元的空字符串视为缺失，拒绝未准备好的数值，计算 inclusive
分位数、Tukey 1.5-IQR 标记及完整配对 Pearson 相关。不提供权重、面板、分类或推断区间；
这些需求另用适当公共工具并注明定义。[虚构案例](examples/cases.md)用于核对边界。

## 验收与停止

- [B] R1 报告来源、观测／抽样单位、依赖和列角色。
- [B] R2 核对数量、缺失、配对分母与实际记录，计算定义可复现。
- [B] R3 不静默删除标记，不把描述关联写成因果、显著性或确认性结论。
- [B] R4 交付报告、计算、所请求的实际图及带证据的要求台账。

一次检查、最多一次针对性补查／修复、一次最终核对。未知单位或未准备的数值阻断依赖项，
独立结果可交付；预算耗尽说明剩余项和最小缺失决定。探索完成不证明后续检验已完成。
