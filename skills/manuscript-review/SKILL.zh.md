# manuscript-review

[唯一发现入口](SKILL.md)。本文件为中文自有主稿，入口为同步英文译文。两份共享
方法、边界、验收与预算；发现文件名不赋予语言语义优先权。来源与变化见
[PROVENANCE.md](PROVENANCE.md)。

## 何时使用

适用于稿件或较完整草稿的论证与证据审查；给定目标期刊时可检查投稿要求。单纯
语言问题用 `prose-audit`，理解已发表论文用 `taskbook-interpret`，组织故事用
`research-story`，实验产物完整性用 `run-review`。可利用运行证据，但不能认证未见
实验，也不能因文字流畅就推断执行合规。

## 方法

1. 确定覆盖和决定。列出所给章节、图表、附录、书目及要求核对的投稿规范，记录
   缺失部分，区分整篇与摘录审查。只索取影响接受决定的材料；否则审可用范围，
   全稿就绪结论保持 blocked。
2. 将关键主张映射到需要的证据和实际所给材料。按主张类型选标准：证明前提与
   步骤、测量与采样、因果识别、公平性能比较、复现条件，或定性材料与竞争解读。
   检查不确定性、成立条件和相关替代解释，不把消融强加给理论或解释研究。摘要
   的主张强度与范围应和正文证据一致。
3. 重建跨章节论证。开头问题是否对应方法和结尾？构念是否稳定、比较是否有理由、
   增量是否区别于背景？检查章节与图是否给后续结论提供前提，是否保留失败和
   负面证据，讨论是否越过样本或协议。缺失证据不等于可编造缺陷；指出具体哪步
   推断没支持，什么来源／检查能解开。
4. 在实际访问范围内检查来源和图表。关键引文是否支持附近主张，书目是否指向
   实际工作；新颖性需最近相关工作，未给材料时按授权检索，未检索不能认证新颖。
   实际检查图表标签、单位、分母、尺度和图注，与正文及可用数据对照。局部指标
   或导出检查不能验证整个实验；此类请求用 `run-review`。
5. 投稿要求与科学判断分开。只按接受的当前期刊／模板规则和明确作者要求检查，
   留来源与版本；不造通用页数、字形禁令、章节数或期刊评分。没期刊可以审内容，
   只阻塞期刊专属就绪判断。语言问题在同一覆盖／预算内用 `prose-audit`，合并
   同一缺陷，不能再交一轮重复审查。
6. 交可落实的定位发现。每项有稳定 ID、原文位置／引文、缺陷、证据、后果、修复
   和状态。按对接受决定的影响区分阻塞、实质修订和小澄清，不按点数公式评分，
   最有后果的修改优先。要求改稿时保留受支持主张并说明变化；不造方法／结果关项。
   对改动主张及受影响前提做一次复查。

为接受的任务与 R1–R6 维护一份验收台账，逐项记录 `done`、`blocked` 或 `n/a`，
附已核对证据或范围理由。方案与建议不能证明下游行动已执行。

## 验收要求

- [B] R1 实际覆盖明确：对照请求核对已查章节、图件、补充材料及缺失部分。
- [B] R2 关键主张有适当支持：沿主张／证据映射核对不确定性与适用范围。
- [B] R3 发现有定位且受证据约束：核对引文／位置、后果及具体修复建议。
- [B] R4 科学与投稿检查分开：核对当前指定规范，未验证新颖性、合规和实验保持未解。
- [B] R5 就绪判断匹配未解项：适用阻塞条件或必要覆盖缺失时不称就绪。
- [A] R6 要求的修改复查一次：核对变化主张及受影响前提；只审校时说明改稿不在范围。

## 何时停止

对接受覆盖做一次完整审查，获准改稿时最多一轮限定修复与复查。决定性公开规则或
文献缺失时，在允许范围内做一批有界获取。审查产物和必需项有证据后交付；审查
完成可以同时稿件未就绪。预算耗尽时说明已查范围、未解发现及最小来源／材料，
不能为了给就绪判断降低科学要求。

## 交付契约

交有覆盖范围的审查、按优先级定位的发现、精简主张／证据与投稿检查、范围受限的
就绪判断和验收台账；请求时才交改稿。保护原始材料、运行和书目；建议修复不能
当已观察结果。摘录审查不能认证全稿投稿。
