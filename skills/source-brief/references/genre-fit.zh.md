# 体裁与材料

情境、证据、历史与比较判断统一见[共同写作判断](writing-foundations.md)。
以下只补充形式选择；已有材料可支持短文或长文，篇幅由请求决定，不增加事实授权。

| 形式 | 组织方式 | 检查重点 |
|---|---|---|
| 决策备忘 | 当前选择、可比证据、实际取舍、建议及未知 | 提案与已作决定分开；不虚构成本或支持意见 |
| 进展说明 | 状态变化、证据、影响、下一步 | 已完成/尝试/受阻/待验证明确，提交不等于部署 |
| 短解释/教程 | 读者问题、必要概念、实例或步骤、失败后的下一步 | 精确保留命令和技术字段；实例说明适用条件 |
| 有来源的叙述 | 已知事件顺序、行为、后果、讲述者知道的范围 | 不补造现场、对白、心理或用户亲历；判断有归属 |
| 选择性技术史 | 当时的问题、条件、方法、证据及后续延续或变化 | 说明年代与范围；区分并行传统，不以先后顺序证明影响或取代 |

现实材料不足时，指出最小缺口；在仍满足请求的情况下交付支持部分。不得为凑
字数扩大同义解释，要求的篇幅无法达到时保持相应项 `blocked`。获准举教学例子
时标明假设或示意，不能把例子写成观察结果。纯虚构作品交给另一个适用能力，
本技能不以来源映射替代人物、情节与世界规则的创作。

体裁改变组织方式，不改变场景的完整交付责任，也不新增审校轮次。

方法来源：经所有者授权，从 `human-writing` 和 `writing-quality` 的体裁选择、
现实材料边界及语义核查方法独立重写。未引入个人语气默认值、固定材料数量/
字数门槛、私有配置、历史案例或专用依赖。公共文本适用仓库 MIT 许可证。
