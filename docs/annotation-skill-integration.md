## 为什么此前仍出现问题

1. **原则已有，读者理解检查执行不足。** 声称有机制解释，不等于读者能辨认变量、层级和真实操作。
   本次在既有共同模块补清关系与解释深度，同时保留科学限制；不靠扩大禁词表处理。
2. **文字约定缺少可执行位置检查。** 书目键存在不证明每个分句归因清楚。本次接入实际的结构检查，
   并将每次名称立即引用保留为显式项目策略，避免把个人阅读偏好扩大成普遍规则。
3. **图表验收遗漏使用能力。** 表格图片可以清楚显示，却妨碍逐字选择与批注。公共指导现在按读者
   用途检查实际 PDF 的文字能力；具体同源导出和标签审计仍由项目工具负责。
4. **软链接可达被误当作系统集成。** 原脚本与规则可被个人会话读取，但旧 hook 没有提供这些新入口。
   本次补入公共源、打包和 hook 代码，并运行命令验证；仍分别报告可达、已调用与宿主自动触发。
