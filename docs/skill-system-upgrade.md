# 技能体系升级与验收

2026-10-08 接受范围为 F01–F12 修复及十二项公共能力补齐。源码目前共有24项技能；
本页按源码、安装、宿主发现、指南读取与实际产物分别记录证据。实际调用仍在核验中，
未以静态检查代替全部验收。

## 来源与私人适配

通用方法使用自包含公开 SOP，私人身份、研究状态、记忆、LAN 配置及机构模板保持私有。
`research-question` 与 `research-story` 保留 Rimagination MIT 来源；`research-diagram` 保留适用的 abstract-fig MIT 方法许可证。
`exploratory-analysis` 与 `manuscript-review` 按接受的产物契约独立编写，未迁入受限／非商业文本。
`source-slides` 独立编写，未把模板许可证误当作整个上游仓库的许可证。
每项新能力的 PROVENANCE.md 记录具体范围与来源。

## 实际验证

- 源码、集合与包：24 skills／4 profiles；120 项 Node 检查通过，审计零错误／零警告，三个生成包与文档构建通过。
- 私人适配：131 项路由检查、新政策19项及组合21项通过，统计有重叠，不相加作为独立样本数。
- 十二项新增能力均有虚构正例与相邻反例。七项方法使用独立CLI普通提示；数据准备→探索分析→实验→只读审查使用一项完整管线。多来源幻灯片另有普通请求选择和真实PPTX／Beamer产物检查。
- CLI轨迹证明新增入口实际读取。概念与文献的相邻任务验证了选择／产物范围，未观察到相邻入口读取；其余证据分别记录，未用名称输出替代指南读取。
- 图解初次备用脚本未由MMD驱动并多出一阶段，已保留失败后做一次限定恢复；最终从MMD实际渲染SVG，查看183mm使用尺寸预览，核对四节点四边和下方图注。
- 幻灯片：实际三页英文PPTX导出后重新导入逐页渲染并查看，备注另查；同来源Beamer实际编译成三页PDF并逐页查看。内置编译器字体访问失败后使用已安装XeLaTeX，记录后端差异。
- 实验：真实helper行为覆盖成功、退出失败、超时及退出0但必需产物缺失；同时检查篡改哈希、错误记录和原运行保护。过程成功不等于科学验证。
- 一次独立复核修正概念笔记R4夸报、故事中可能暗示统计显著性的词及图解；原始产物与日志保留，未把初次进程退出0当验收通过。

## 发现证据与边界

源码安装到两个既有发现目录，各24项链接正常。一次成功的独立CLI会话观察到159项注入技能，其中metis 24/24；113个绝对可读来源据此刷新，历史未观察或别名根未知者保留历史身份和unknown。桌面子代理新阶段观察到24项实际注入；本轮后续父会话的开发者清单也已实际刷新到24项。清单暴露不等于所有普通任务都自动读取正文，具体调用另看轨迹。

CLI本机配置和内置默认模型先被账户拒绝；验证根据本机可用模型缓存使用临时gpt-5.5参数，未更改全局配置。这一证据不代表桌面模型行为一致。DOI初测仍走私人入口；收窄私人后端适配并改进公共发现描述后，唯一新会话完整读适配边界、直接进入scansci-pdf，不回跳router。已有本地PDF用阅读能力，未执行下载或用该路由测试声称问答正文已验收。

完整自然请求、读取事件、产物哈希、逐项需求及原失败记录保存在本机忽略的任务工作记录；公开目录只保留虚构独立样例、方法来源和这份范围说明。验证支持这些代表性输入，不能证明所有数据、语言、宿主或后端组合均有效。
